# Draft Cover Letter For International Journal Of Health Geographics

Dear Editors,

We submit "An open benchmark for country-level reported hantavirus incidence:
retrospective one-year-ahead evaluation under sparse public surveillance" for
consideration in International Journal of Health Geographics.

This manuscript presents an ECDC-only EU/EEA country-year benchmark for
reported hantavirus infection incidence from 2019-2023. It links authoritative
annual surveillance labels to public demographic, land-use, climate, and
geospatial sources, then evaluates probabilistic retrospective one-year-ahead
predictions with WIS, coverage, sharpness, MAE, Brier score, and sensitivity
analyses.

The work is intended as a geospatial public-health benchmark rather than a live
alerting tool. Existing public trackers aggregate signals; this study provides
a frozen, reproducible benchmark that tests whether public climate and land-use
covariates improve country-year reported-incidence evaluation over strong
surveillance baselines. Mixed and negative results are retained.

The manuscript should fit IJHG because it combines GIS-enabled surveillance,
public covariate construction, country-level maps, source-quality metadata, and
transparent uncertainty evaluation. All analyses use aggregated public data;
no individual-level data were accessed.
