# Manuscript Statements

## Data Availability

The benchmark is rebuilt from public ECDC Annual Epidemiological Report data
and public covariate sources documented in the repository. Generated data are
not committed to git by default; they can be regenerated with the scripts in
`docs/reproducibility_manifest.md`. Final processed tables should be deposited
on Zenodo, OSF, or Figshare only after the owner account and license are
confirmed.

## Code Availability

All source code for data rebuilding, validation, feature ablation, maps, and
quality checks is maintained in the public repository. A release tag and DOI
should be added before journal submission.

## Ethics

This study uses aggregated, publicly available surveillance data at the
country-year level. No individual-level patient data were accessed. Ethical
review was not required for secondary analysis of publicly available aggregate
data under the applicable institutional policy.
