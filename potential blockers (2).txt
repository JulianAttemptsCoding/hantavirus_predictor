# Possible Blockers for HANTA-PINN-ST

## Data Blockers
- **CDC WONDER geocoding restriction** — county-level case data may require data use agreement; FIPS-level coordinates not public
- **NEON seroprevalence data gaps** — many sites lack hantavirus serology; only ~2.1% overall seroprevalence means sparse positive labels
- **SafeGraph/Meta mobility access denied** — academic applications often rejected or take 4–8 weeks
- **ERA5 API rate limits** — CDS throttles to 3 concurrent requests; 30-year global extract can take days
- **MODIS cloud contamination** — 16-day NDVI composites still have gaps in cloudy regions; requires gap-filling
- **Transfer source misalignment** — dengue/leptospirosis case definitions, reporting cadence, and spatial units differ from hantavirus

## Technical Blockers
- **torchdiffeq memory explosion** — dopri5 adaptive solver with 50K trajectories × 730 timesteps × 8 compartments can OOM on single A100
- **PyTorch Geometric installation failure** — CUDA version mismatches common; `torch_sparse`/`torch_scatter` compilation errors frequent
- **GATv2 over-smoothing** — 3-hop message passing on sparse county graphs may collapse node representations
- **Mixed precision NaNs** — FP16 training unstable with ODE residuals; gradients can explode near bifurcation points
- **Dask deadlocks** — distributed raster alignment across MODIS/ERA5/CHIRPS with different CRS and resolutions hangs
- **Hydra config resolution bugs** — nested YAML overrides with `++model.pinn_core.ode_rtol` fail silently

## Scientific Blockers
- **Synthetic data distribution shift** — moment-matching to NEON doesn't guarantee realistic rodent social structure or spatial heterogeneity
- **R₀ identifiability** — K(t) and β(t) are structurally confounded; PINN may learn wrong parameter combinations that still fit data
- **Transfer learning negative transfer** — dengue (vector-borne, urban) may hurt hantavirus (reservoir-borne, rural) performance if feature spaces diverge
- **Conformal prediction under covariate shift** — 90% coverage on training climate regime may fail under 2024–2026 El Niño
- **Andes H2H β_HH unidentifiable** — only ~8 cruise ship cases with contact tracing; Bayesian posterior will be extremely wide
- **Sex-structured SEIR overfit** — 8 compartments with only 46 NEON sites = high parameter-to-data ratio

## Operational Blockers
- **GPU availability** — 4× A100 × 48h training runs cost ~$500–$1,000 on cloud; academic clusters have 2-week queues
- **Docker image size** — CUDA 12.4 base + PyTorch + geospatial libs = 8–12 GB; slow push/pull
- **W&B / MLflow quota exhaustion** — 50K synthetic trajectories × 500 epochs = massive artifact storage
- **DVC remote setup** — requires S3/GCS bucket with credentials; institutional IT often blocks

## Publication Blockers
- **Reviewer skepticism on synthetic data** — *Nature Communications* reviewers may reject any model trained primarily on simulated data
- **No prospective validation** — retrospective validation on 1993–2023 is weaker than live forecasting; no held-out 2024–2026 test yet
- **Ethics/IRB for human mobility** — SafeGraph data may trigger IRB review if linked to health outcomes
- **Competing preprint** — another group may publish a hantavirus PINN before submission (field is heating up post-MV Hondius)
- **Page limit** — *Nature Communications* methods section is short; fitting SEIR-SDE derivation + PINN architecture + GNN + transfer learning + uncertainty into 5,000 words is extremely tight

## Timeline Blockers
- **Week 3 synthetic validation failure** — if KS-test p < 0.05 on seroprevalence, entire pre-training strategy collapses
- **Week 6 ODE divergence** — if residual doesn't converge below 1e-3, physics loss weight tuning becomes a rabbit hole
- **Week 9 transfer negative results** — if fine-tuned model underperforms baseline, architecture redesign needed mid-project
- **Week 12 WIS not beating baseline** — if WIS reduction < 15%, journal rejection likely regardless of novelty
